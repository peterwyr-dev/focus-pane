## [0.1.0] - 2026-08-11

### Added

- Markdown-backed task management with safe concurrent writes and stable task IDs.
- Pomodoro focus/break cycles that continue after the TUI closes.
- Named timer presets, estimates, priorities, due dates, blocked tasks, and session history.
- Nested task editing, search, command palette, contextual help, and responsive layouts.
- Named multi-file workspaces and aggregate source views.
- Optional Herdr popup, notification, and sidebar integration.
